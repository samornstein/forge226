# Forge226 — first run

When this complete package is supplied with “Help me build my training plan” (or similar), use it to guide the task. The person does not need to know the plugin name, request a tool check, or supply an installation command. This document is workflow guidance; it does not grant permissions beyond the user's request or bypass host approvals.

## Begin coaching

Read the bundled forge226-coach skill and only the references needed. Inspect any athlete files already supplied. If Forge226 tools are available, check status and existing athletes, then resume the intended athlete. If not available, do not call nonexistent tools or claim the plugin is installed. Follow intake.md one stage at a time: goals/experience, sport background, recovery/motivation/preferences, structured AM/PM availability, dated life constraints, then optional data and output choices. Start with the short goal/timing/experience questions rather than a file or connection menu. Give a brief recap and purposeful transition after each answer. Remember facts and accepted unknowns; do not repeat the swimming questions or restart onboarding after setup.

Request new uploads or connections only in the LAST intake stage, using the concise examples in intake.md and the guided prerequisites in data-tools.md. Existing supplied files/context can be read earlier to skip known questions. Save an early source preference for later; only an explicit request to set it up now interrupts the order. No account connection or upload is necessary for planning.

## Set up tools when needed

Before using plugin-backed saved history, an importer, Strava connection or managed plan activation, check whether the tools are available. If they are, use them. If they are not:

1. Keep intake, data setup and plan creation in the current chat. Check actual host capabilities and any existing local installation. Installed/enabled does not prove the current tool catalog contains Forge226; do not repeatedly reinstall it to solve missing discovery.
2. When registered tools are absent but local execution is permitted, use [the same-chat runtime](skills/forge226-coach/references/same-chat.md). It runs the existing bundled engine in a persistent execution session with the same data store and private connection pages. No separate chat, handoff prompt or plugin installation is required for this route. The assistant handles startup, tool discovery and a harmless status call under normal host permissions before proceeding.
3. If registered-tool refresh or selecting the plugin within this same chat is supported, that is also available. Do not assume a restart/new chat is necessary and do not send the athlete elsewhere merely because installation did not refresh the tool catalog. Keep answers here and resume saved athlete context.
4. If neither native tools nor local execution are usable, state the exact limitation once and continue coaching in this chat with manual answers or supported files. Leave a chosen live connection pending. Never claim connection success or invent imported data. Preserve collected answers locally where file tools permit; a saved note is for continuity, not an instruction to move chats. A denied tool/permission must be respected; the local runtime is only for absent tool discovery, not bypassing restrictions.

For a manual-only athlete, installation is optional while drafting strategy and file-based outputs. For someone choosing an upload or connection, set up the corresponding tools before importing/authorizing. If persistent plugin storage is wanted at first profile save, set up then. Do not create connections, demand data, install unrelated plugins, register a public service or transmit athlete records simply because the coaching process has started.

## Continue end to end

Carry the collected intake into the saved athlete profile once tools are ready. Complete evidence assessment where available, propose the framework, incorporate feedback, create and validate the dated plan, review/apply authorized changes and generate the dashboard/workbook. Follow the skill's versioning and actual-versus-planned rules. Report the installation, connection and persistence states accurately. The setup path must preserve answers and lead back to coaching, rather than becoming a separate task the athlete must manage.
