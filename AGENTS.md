# Forge226 coaching package

For requests to build or maintain a training plan with this package, read START-HERE.md, then skills/forge226-coach/SKILL.md. Begin coaching from a simple user request. Handle missing tool setup at the step that needs it, following host permissions; do not require a separate technical prompt. Do not apply these instructions to unrelated tasks. Keep athlete data outside this distributable folder.

Keep training intake, connections and planning in the same chat. If registered tools are absent, follow the bundled same-chat runtime guidance under normal host permissions; do not send the athlete to another chat or require a handoff.

For a new training plan, follow the six guided intake stages in intake.md. Ask only the current stage, collect qualitative context and save optional file/connection setup until the end. Reuse existing answers and supplied evidence.
